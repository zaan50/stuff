# Interview Preparation Topics

| Sl. No. | Area | Topics |
|---:|---|---|
| **1** | **Java Concepts** | - What are `equals()` and `hashCode()`? Explain their contract and typical overrides.<br>- Explain the internals of `HashMap` (hashing, buckets, resizing, load factor, collision handling).<br>- Checked and Unchecked Exceptions<br>- Upperbound and Lowerbound uses in Generics<br>- When would you use a `HashMap` vs a `TreeMap`? What are the performance trade-offs?<br>- What is the use of `ExecutorService`?<br>- How does garbage collection work in Java? Have you ever dealt with a memory leak — how did you diagnose it? |
| **2** | **Spring Boot Concepts** | - What is `@Autowired`?<br>- Explain Dependency Injection in Spring Boot. How is it implemented and why is it important?<br>- What is auto-configuration in Spring Boot and how does it work internally?<br>- What is Spring Initializer and how does it help in setting up a project? |
| **2** | **Practice Questions** | - Implement your own version of String Compression<br>- Find duplicates / unique elements<br>- Basic tree traversal<br>- Frequency-based sorting / grouping logic<br>- Longest substring / Sliding Window pattern<br>- Graph / Tree problems<br>- HashMap logic<br>- Parsing strings or logs<br>- Reconstructing data from input<br>- Implementing simple algorithms (grouping, mapping, flattening structures) |
| **3** | **Programming Questions** | **Classes already defined — read through and understand the code.**<br><br>1. The test for a service is not passing due to a bug in the code. Make the necessary changes to fix the bug and extend the code.<br><br>2. Develop a stock trading data management software that tracks the prices of different stocks over time and provides useful statistics. |

## Condensed Preparation Areas

| Category | What to Prepare |
|---|---|
| **Core Java** | `equals()` / `hashCode()`, HashMap internals, Exceptions, Generics bounds, HashMap vs TreeMap, ExecutorService, Garbage Collection & Memory Leaks |
| **Spring Boot** | `@Autowired`, Dependency Injection, Auto-configuration internals, Spring Initializer |
| **DSA / Coding** | String compression, duplicates / unique elements, tree traversal, frequency sorting / grouping, sliding window, graphs / trees, HashMap problems, string / log parsing, data reconstruction, grouping / mapping / flattening |
| **Programming / Debugging** | Read existing classes, understand service code, identify and fix failing tests, extend existing implementation |
| **Domain Problem** | Stock trading data management — track stock prices over time and calculate useful statistics |
